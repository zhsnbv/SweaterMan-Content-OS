## WHAT WE KNOW

- **FACT.** 4 ролика ≥100K просмотров на YouTube: V001 Титаник (1 936 194), V026 тайные дружбы ч.2 (488 225), V019 рыба-луна (455 082), V022 пьяные пчёлы (143 819). Они дают **92,5 % просмотров** и **87,8 % подписок** из суммы по 26 роликам.
- **FACT.** Удержание почти не различает ролики: avg % viewed от 38,9 до 63,5 %, медиана 45,9 %; у 22 из 26 роликов — в пределах 0,85–1,10× медианы.
- **FACT.** Подписки на 1000 просмотров: медиана 1,29, диапазон 0,34–3,42.
- **FACT.** Выручка YouTube за 90 дней: **$78,99** на ~3,2M просмотров (≈ $0,025 за 1000). TikTok Est. rewards: **$0,00**. Рекламная монетизация площадок сейчас не является значимым доходом.
- **FACT.** Темп публикаций снизился: V001–V018 — 18 роликов за 61 день (~2/нед); V019–V026 — 8 роликов за 60 дней (~1/нед). Более высокий reach пришёлся на период более редких публикаций (причинность не установлена).
- **FACT (грубый масштаб).** За сопоставимые ~60 дней: TikTok 7,4M post views, Instagram 3,5M reel views, YouTube канал ≈2,0M views. Определения «просмотра» на площадках разные — это масштаб, не сравнение качества.

## STRONG SIGNALS
*«Сильный» здесь = самый надёжный из доступного, а не статистически доказанный.*

1. **Результат определяется редкими хитами, а не средним роликом.** 4 из 26 роликов = ~90 % результата. `FACT` по концентрации; следствие для стратегии — `SIGNAL` (confidence: medium). Оценивать форматы по медиане, а хиты рассматривать отдельно.

2. **Ролик нельзя судить по первой неделе.** `FACT` на уровне отдельных роликов:
   - V022 (пчёлы): за первые 7 дней — 3 947 просмотров (2,7 % итога); **96 % просмотров пришли через ~7 недель**, 16–19 сентября.
   - V001 (Титаник): волны по 50–120K/день в июле–августе, через 2–3 месяца после публикации.
   - V019 (рыба-луна), напротив, классический стартовый хит: 96 % просмотров за первую неделю.
   - Обобщение на все форматы — `SIGNAL` (daily-данные есть только по 5 роликам).

3. **С середины июля «пол» просмотров вырос.** Из 8 роликов, опубликованных с 14 июля (V019–V026), 7 набрали ≥32K; исключение — V021 (5 896). До этого V014–V016 — 3–5,5K. Корреляция просмотров с порядком публикации в когорте B: Spearman 0,73. `SIGNAL` (confidence: medium). **Причина UNKNOWN**: рост канала, алгоритм и смена тематики (почти всё с июля — животные) смешаны.

4. **Чем шире охват, тем ниже конверсия в подписку — но абсолютные подписки всё равно дают хиты.** Spearman(views, subs/1k) в когорте B = −0,52. V019: 0,34 subs/1k, но 153 подписки; V001: 0,91 subs/1k, но 1 754 подписки. `SIGNAL` (confidence: medium; типичный паттерн для Shorts).
